# Engine data coverage — KSA 2026.9.7.5402

A source-to-editor audit closed engine import, scope, authoring, persistence, preview and export gaps missed by incremental game-update checks.

This audit uses `../ksa-game-assemblies/current/decomp/KSA/` and the corresponding `Content/Core/` snapshot. It supplements [scope/engines.md](../scope/engines.md), [scope/plumbing-and-feeds.md](../scope/plumbing-and-feeds.md), and [docs/engines.md](../docs/engines.md). Scope here is the engine data supported by current KSA Part templates and its referenced Core catalogs. Runtime vehicle state and authoring entirely new external asset libraries are identified separately below.

## Part-template field inventory

Every row below is represented in the document model, read/written by the XML parser/serializer, retained by project save/export, and exposed by the named editor. Module identity is preserved on import and generated on creation; most module IDs are displayed/read-only rather than independently renameable. Reference fields are editable. Shared template data produces one runtime module per placement.

## Validation and data lifecycle

- Production catalog import merges geometry and GameData across files. Adding one SubPart imports its metadata in the placement undo step. Complete Part import includes Part modules, template modules, wiring and controllers, then opens its main chamber scope on entry to Engine mode.
- Part export makes private SubPart variants rather than mutating Core templates. Both controller scopes, hardware, references, plume rows and inherited grain fields pass through the same serialization path.
- Load-blocking checks cover owner-relative missing references, duplicate module IDs and multiply bound hardware, mixed solid/liquid rockets, empty solid nozzle bindings, missing mixture ratios, incompatible solid reactions and pressure limits, solid motors driven by RCS controllers, and invalid grain casing mass sources. Other KSA log-only conditions remain warnings.
- Add/remove/duplicate operations enroll in undo. Text/number edits use existing interaction-start undo; plume shortcut changes push their own discrete step.
- New fields use constructor defaults and normalizer coverage. Neither persisted version is bumped: compatible saved work survives. Previously stored raw SubPart controller XML stays raw, is preserved on export/paste, and its placement references are remapped. It is not migrated into typed controllers; a fresh built-in import exposes the new typed editor.
- Portable regression tests use byte-identical Core propulsion fixtures. The live integration test traverses all 38 current Core engine Parts, evaluates liquid performance, evaluates locally resolvable solid curves, exports a mod and reimports it. Browser smoke covers the actual EngineA3 import/mode switch and RCS controller editing.

## Explicit boundaries

- Vehicle assembly can extend a solid stack through connectors into neighboring Parts. Flexo cannot infer those Parts from a single Part document. Connector-fed curves are unavailable with a reason, rather than showing a misleading partial stack. Runtime ignition, throttle/staging state, vehicle plumbing flow, and save-only reaction/per-segment grain overrides are not Part-template fields.
- Core reaction, grain geometry, substance, plume and sound **library definitions** are referenced dependencies. Creating a new two-dimensional MixtureReaction library, grain-profile LUT library, substance library, plume renderer or sound bank is outside the Part editor; selecting their existing IDs is supported. Custom FixedReaction definitions are the supported embedded authoring path. This does not discard any built-in engine's referenced Core data on mod export: the mod depends on Core.
- ThermalReaction exists in the catalog but current KSA has no corresponding Part thermal core. Electric/ion power coupling likewise needs game code, not additional Part XML fields.
- Verification is against the current decompiled contract and automated import/editor/export tests. It does not constitute an actual KSA game launch or mod load.
